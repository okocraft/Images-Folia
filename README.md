Also, to reduce build time, only the latest (single) Minecraft version is supported.

## How to compile

Just run a following command.

```bash
./gradlew build
```

Then, jars will be created in `build/libs`. The plugin jar is `Images-VERSION-mc1.xx.x.jar`.
